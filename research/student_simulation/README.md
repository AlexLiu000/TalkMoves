## 复现检查

需要 Python 和 openpyxl，执行：

```sh
python research/student_simulation/audit.py
```

脚本扫描 `Subset 1`、`Subset 2` 的全部原始工作簿，比较增加 dialogue acts 的对应版本，检查现有 TSV 的结构和完全相同文本对的交集。脚本不执行上游 notebook，不改变原始数据。

结果保存在`audit_output/`，该目录可重建，不默认纳入git。本次审查的汇总快照为`baseline_summary.json`。运行结果还包含逐课统计、增强版对照和较大的`review_candidates.jsonl`候选清单。所有自动警示都只是候选项，不等同于数据错误、补标结果或删除决定。

## 使用原则

1. 原 TalkMoves 标签优先复用。保留原始值，另设标准化值和映射来源；原始标签编号与 TSV 的 0 起始编号分开记录。
2. 生成训练从原始课堂文件重新构建；保留标点、小数点、括号中的有用记录和原始说话者。不得直接复制分类任务的清洗方法。
3. 保持文件和行号来源。轮次编号可能缺失，同一编号可能跨多个说话者；它不能单独定义一轮回答。
4. 不将 `S`、`SS` 或跨课同名视为同一个学生。即使有姓名，也需验证本课内是否稳定。
5. 数值型句子可能是真实数学回答，应保留原值和原类型；不能因不是字符串就删除。
6. 两个标注列都有值可能来自 `7 - Context`，不能直接排除。明显不合法的值与合法的双列标注分开判断。
7. 原标签描述话语行为，不直接证明正确、掌握、误解或学习。原标签没有覆盖的内容不自动视为无意义。
8. 教师候选人最初与单个模拟学生互动。依赖同伴、合唱、视频角色或不可见图示的材料需单独判断其适用范围。
9. 对话历史仅包含目标回答之前的信息；后续教师纠正可辅助人工分析，但不得泄漏到该回答的生成输入。
10. 五节已共同阅读的课是开发材料。最终评价按课堂/教师等适当单位隔离；现有分类任务划分仅作参考。

## 共同讨论记录

`DISCUSSION_CASES_ZH.md`提供首批十个片段的完整上下文，适合直接阅读。`discussion_queue.jsonl`保存其结构化版本，每个都包含原始文件、Excel行号、原话及原标注。`status=pending`表示尚未共同裁定。`proposed_action`是AI建议，不是已完成的人工标注。

补标只增设研究用途需要的字段：

- `speaker_role_reviewed`：现场教师、现场学生、群体、录播内容、不确定。
- `context_sufficiency`：对指定用途足够、不足、不确定，并写明缺什么。
- `use_decision`：可作生成目标、仅作上下文、暂缓、排除目标；必须注明具体任务。
- `educational_observation`：仅记录可定位的理解/策略/不确定性证据，可留空。
- `evidence_rows`、`rationale`、`annotator`、`review_status`：依据、理由、实际标注者和状态。

每次只讨论一个片段。先看原话和原标签，再判断是否需要补充，最后记录用途决定。不要求给所有句子标注心理特征。人机共同讨论不是独立人工标注者间一致性证据。
